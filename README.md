# 🫁 Lung Cancer Mortality Analysis — Power BI

## 📊 Project Overview

This project focuses on analyzing and visualizing **lung cancer mortality data using Microsoft Power BI**.

The objective of the project is to transform mortality data into interactive and easy-to-understand visualizations that can help identify patterns, trends, and differences across the available dimensions in the dataset.

The project demonstrates the use of **data visualization, data analysis, dashboard design, and business-oriented reporting** using Power BI.

---

## 🎯 Objectives

The main objectives of this project are to:

* Analyze lung cancer mortality data.
* Transform raw data into meaningful visualizations.
* Identify patterns and trends within the available data.
* Present key information through an interactive Power BI dashboard.
* Create a clear and user-friendly data visualization report.
* Demonstrate practical skills in data analysis and dashboard development.

## 🔍 Analysis Performed

The project includes analysis and visualization of lung cancer mortality data using Power BI.

The dashboard was designed to make the data easier to explore and understand by presenting information through charts, graphs, and other visual elements.

The analysis focuses on:

* Mortality patterns
* Comparison across available categories
* Trends within the dataset
* Distribution of mortality data

3. Explore the dashboard and available visualizations.
4. Use the interactive filters and visuals to analyze the data.

> **Note:** Microsoft Power BI Desktop is required to open the `.pbix` file.
